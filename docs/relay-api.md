# Relay API

## Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/messages` | Submit an encrypted message |
| `GET` | `/messages/{hash}` | Fetch encrypted messages |
| `DELETE` | `/messages/{hash}/{id}` | Acknowledge and delete a message |
| `GET` | `/health` | Health check |
| `GET` | `/stats` | Queue statistics |

## POST /messages

### Request body

```json
{
  "to": "<sha256(recipient_pubkey) hex>",
  "from": "<sha256(sender_pubkey) hex>",
  "payload": "<base64 NaCl encrypted blob>"
}
```

### Notes

- `to` identifies the recipient queue.
- `from` is optional if your implementation allows anonymous sender delivery.
- `payload` is an encrypted message blob generated by the client.

## GET /messages/{hash}

Returns queued encrypted messages for the specified recipient hash.

### Query parameters

- `since=<msg_id>` — return only messages after this ID
- `timeout=<s>` — long polling timeout, maximum 30 seconds
- `limit=<n>` — maximum number of messages per response, default 50

## DELETE /messages/{hash}/{id}

Removes a message after successful receipt or acknowledgement.

## GET /health

Returns basic health information for monitoring and orchestration.

## GET /stats

Returns queue statistics exposed by the relay implementation.
